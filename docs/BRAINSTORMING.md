# App

Spectra Black is a new app combining Avee RE Player (originally made by Daaw Aww, modded by Cubiq). The idea is to combine all useful features from
both apps (Avee Player/Avee RE Player and After Effects)

# Features

- Keyframes (Like After Effects)
- Project file explorer (Like After Effects)
- Elements/Plugins (Like AE and Avee)
